Exited to annouce my first proper self built Full Stack Project: Axion




It is mobile first Web Application that helps people to communicate with people.




The journey of this project isnt straight-farward, A failed full stack project that lacked achitecture planning taught me the importance of Achitecture & System design & Planning.




I took those lessons and applied them to this project.


(Bugs and missing features are expected)

 Although it is under development, but i have decided to share the progress with the community, I will introduce more features with time in it.




What Axion includes:




1. User Authentication.

2. Real Time one-to-one messaging.

3. Chat history.

4. 24-hour highlights(like Whatsapp Statuses).




Technologies used:




Frontend: React, TypeScript, Tailwind CSS, Redux Toolkit

Backend: Node.js, Express.js, TypeScript

Database: PostgreSQL

Real-time communication: Socket.IO
